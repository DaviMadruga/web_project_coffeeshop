# Triple Espresso

## Descrição do projeto

O **Triple Espresso** é uma página web desenvolvida para a cafeteria da biblioteca Triple Peaks.

O projeto apresenta informações sobre a cafeteria, como horários de funcionamento, endereço, receitas de café em vídeo e uma seção para reserva de mesas.

O projeto foi desenvolvido utilizando:

- HTML5;
- CSS3;
- Metodologia BEM para organização das classes CSS;
- Flexbox para construção e alinhamento dos layouts;
- Formulários HTML;
- Incorporação de vídeos do YouTube;
- Google Fonts.

## Planos de melhoria

Como melhoria futura, pretendo tornar o endereço da cafeteria interativo.

Atualmente, o endereço é apresentado apenas como texto. A ideia é transformá-lo em um link que permita ao usuário abrir diretamente a localização da cafeteria no **Google Maps**.

Também seria possível, futuramente, incorporar um mapa diretamente na página para que o usuário possa visualizar a localização sem precisar sair do site.

Outra melhoria seria a criação de uma galeria de fotos, com imagens da cafeteria, do ambiente, dos produtos e também de clientes. Essa galeria ajudaria a apresentar melhor o espaço e proporcionaria ao visitante uma ideia mais clara da experiência oferecida pela cafeteria.
